# Changelog

All notable changes to Claude Unity Assistant will be documented here.

## [1.0.0] - 2026-05-10

### Added
- In-editor Claude chat window (`Window > Claude Assistant`)
- Auto-fix compile errors with one click
- MCP server for Claude Desktop integration (`Window > Claude MCP > Start Server`)
- VRChat support: UdonSharp, PhysBones, AudioLink, VRCSDK3, Quest optimization
- Persistent chat history saved between Unity sessions
- Quick buttons: Fix Errors, Explain Error, New Script, VRChat Help
- `Ctrl+Shift+A` shortcut to open, `Ctrl+Enter` to send
- Auto-detects active scene and selected GameObject for context
